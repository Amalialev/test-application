# עמוד לידים — "צליאק בכיתה: מה חשוב לדעת"

עמוד נחיתה בקובץ אחד (`index.html`). אוסף שם, טלפון ואימייל, שולח אותם ל־Brevo,
ומיד חושף את המדריך המלא באותו עמוד. בנוי כדי להיות מודבק כלינק במאניצ'ט.

**מה צריך לעשות בפועל: להדביק כתובת אחת ולהעלות את הקובץ.** זהו.

---

## מה עושים, לפי הסדר

### 1. ליצור טופס ב־Brevo

Brevo → **Contacts → Forms → Create a form**.

שלושה שדות: **EMAIL**, **FIRSTNAME**, **SMS**. אלה השמות שהעמוד מצפה להם, ואלה
גם ברירת המחדל של Brevo — אין מה לשנות.

שומרים, ואז נכנסים ל־**Share** או **Embed** ומחפשים בקוד את השורה:

```html
<form action="https://sibforms.com/serve/MUIFxxxxxxxxxxxx" ...>
```

מעתיקים **רק את הכתובת** שבתוך הגרשיים.

### 2. להדביק אותה בקובץ

פותחים את `index.html` בעורך טקסט כלשהו. בשורה 21 בערך, ממש בראש הקובץ:

```js
var BREVO_FORM_URL = "";
```

מדביקים בין הגרשיים:

```js
var BREVO_FORM_URL = "https://sibforms.com/serve/MUIFxxxxxxxxxxxx";
```

שומרים. **זו העריכה היחידה בקובץ.**

> אם השורה נשארת ריקה, יופיע בראש העמוד פס אזהרה אדום שאומר שהעמוד לא מחובר.
> זה מכוון — כדי שלא תעלי לאוויר בטעות עם טופס שלא שומר כלום.

### 3. להעלות לאוויר

הקובץ עצמאי לגמרי — אין קבצים נלווים ואין תלויות. אפשר להעלות אותו לכל מקום:

- **לאתר הקיים שלך** — להעלות ל־FTP לתיקייה, ומקבלים `amalialev.com/celiac/`
- **Netlify Drop** — גוררים את התיקייה `landing` ל־app.netlify.com/drop,
  ומקבלים כתובת מיד
- **GitHub Pages** — מפעילים Pages ומצביעים על התיקייה `landing`

### 4. לחבר לדומיין שלך (רשות)

אם העלית ל־Netlify ורוצה כתובת על amalialev.com: ב־Netlify **Domain settings →
Add custom domain**, מקלידים תת־דומיין כמו `madrich.amalialev.com`, ומוסיפים
אצל ספק הדומיין רשומת CNAME לפי מה ש־Netlify מציג. תעודת SSL נוצרת אוטומטית.

תת־דומיין לא נוגע באתר הקיים שלך בכלל.

### 5. לבדוק שזה עובד

נכנסים לעמוד, ממלאים את הטופס בפרטים אמיתיים שלך, ובודקים ב־Brevo תחת
**Contacts** שאיש הקשר נוסף. אם כן — סיימת.

לבדיקה חוזרת מאותו דפדפן: העמוד זוכר שכבר מילאת ומדלג על הטופס. פותחים חלון
פרטי, או מנקים את אחסון האתר בכלי המפתחים.

### 6. להדביק במאניצ'ט

מדביקים את הכתובת כמו שהיא:

```
https://madrich.amalialev.com/
```

## מה קורה מאחורי הקלעים

הגולש/ת ממלא/ת → הדפדפן בודק שהשדות תקינים → בונה טופס נסתר עם השדות
בשמות ש־Brevo מכיר → שולח אותו לתוך `iframe` נסתר → המדריך נפתח.

ה־`iframe` הוא הטריק היחיד כאן, והוא פותר שתי בעיות בבת אחת: הגולש/ת לא
מנווט/ת לדף התודה של Brevo אלא נשאר/ת בעמוד, ואין צורך בהגדרות CORS.

שני דברים שקורים אוטומטית ואין מה להגדיר:

- **הטלפון מנורמל** ל־`+972521234567`, כי זה מה ש־Brevo דורש בשדה SMS
- **מלכודת ספאם**: שדה נסתר בשם `company`. בוט שממלא אותו לא נשלח ל־Brevo,
  ולא רואה הודעת שגיאה שתסגיר לו את זה

> לא לשים בקובץ הזה מפתח API של Brevo בשום מצב. הקובץ גלוי לכל מי שנכנס לעמוד.
> כתובת הטופס (`sibforms.com/serve/...`) בנויה להיות ציבורית — מפתח API לא.

## אם משהו לא עובד

**מילאתי את הטופס ולא הופיע איש קשר ב־Brevo.**
פותחים את העמוד, לוחצים ימני → Inspect → לשונית Network, וממלאים שוב. אמורה
להופיע שורה אל `sibforms.com`. אם היא מופיעה באדום, הכתובת שהדבקת שגויה או
שהטופס ב־Brevo נמחק. אם היא לא מופיעה בכלל — `BREVO_FORM_URL` ריק.

**איש הקשר נוסף אבל בלי שם או בלי טלפון.**
שמות השדות בטופס שלך שונים מברירת המחדל. פותחים את קוד ההטמעה של Brevo,
מסתכלים על ה־`name=` של כל שדה, ומעדכנים בהתאם את `FIELDS` בתחתית הקובץ.

**Brevo דוחה את הפנייה.**
בקוד ההטמעה שלו יש שדות נסתרים. משווים אותם ל־`HIDDEN` בתחתית הקובץ
(בעיקר `locale`) ומתקנים כך שיתאימו.

## מה עוד יש בעמוד

- **ולידציה בעברית** לשם, לטלפון (פורמט ישראלי, כולל ‎+972) ולאימייל
- **צ'קבוקס אישור דיוור** — חובה לסמן לפני שליחה. הסימון הוא התיעוד המשפטי
  שלך להסכמה; הוא לא נשלח ל־Brevo כשדה, כדי לא להתנגש באטריביוטים שלך
- **תוכן עניינים** בראש המדריך, לקפיצה מהירה — בעיקר בשביל מובייל
- **כפתורי הורדה והדפסה** גם בראש המדריך וגם בסופו
- **זיכרון מקומי**: מי שכבר מילא פעם אחת מקבל את המדריך ישירות בכניסה הבאה
- **גיליון הדפסה** נפרד: הטופס נעלם, המדריך יוצא נקי ל־PDF, והכרטיס לתלייה
  לא נחתך בין עמודים
- **שדות למילוי** בכרטיס ובפרטי התלמיד/ה — אפשר להקליד לפני ההדפסה או ההורדה

### כפתור ההורדה

ההורדה בונה בדפדפן קובץ HTML עצמאי שמכיל רק את המדריך — בלי הטופס ובלי
הכפתורים — כולל כל העיצוב וכולל מה שהוקלד בשדות. הקובץ נפתח בכל דפדפן גם בלי
אינטרנט (רק הפונטים ייפלו לפונט מערכת), ואפשר לשלוח אותו הלאה בוואטסאפ או במייל.

הוא יורד בשם `madrich-celiac-bekita.html`. השם באנגלית בכוונה: חלק מהדפדפנים
פוסלים שם קובץ בעברית ושומרים אותו כ־`download` בלי סיומת, וכך הוא לא נפתח
בלחיצה.

## הערות

הפונטים (Assistant + Frank Ruhl Libre) נטענים מ־Google Fonts, כך שנדרש חיבור
אינטרנט. אם רוצים עמוד שעובד גם בלי — מוחקים את שתי שורות ה־`<link>` ל־fonts
והדפדפן ייפול חזרה לפונט מערכת.

החשיפה של המדריך היא בצד הדפדפן. מי שיודע לפתוח כלי מפתחים יוכל לעקוף את
הטופס. זה סטנדרטי בעמודי לידים; אם חשוב חסימה אמיתית, צריך להגיש את המדריך
משרת אחרי אישור הליד.
