# עמוד לידים — "צליאק בכיתה: מה חשוב לדעת"

עמוד נחיתה בקובץ אחד (`index.html`): אוסף שם, טלפון ואימייל, שולח את הליד לבראבו,
ומיד אחר כך חושף את המדריך המלא באותו עמוד — כולל כפתור הדפסה / שמירה כ־PDF.
בנוי כדי להיות מודבק כלינק במאניצ'ט.

---

## 1. חיבור לבראבו — החלק היחיד שצריך לערוך

בתוך `index.html`, בתחתית הקובץ, יש בלוק הגדרות מסומן:

```js
var BRAVO = {
  action: "",                 // ← כתובת ה-action של הטופס מבראבו
  fields: {
    name:    "name",          // ← שם השדה (name=) שבראבו מצפה לו עבור שם
    phone:   "phone",         // ← ...עבור טלפון
    email:   "email",         // ← ...עבור אימייל
    consent: "consent"        // ← שדה אישור דיוור, אם קיים אצלך. אפשר למחוק
  },
  extra: {
    // "list_id": "12345",    // ← שדות נסתרים נוספים שבראבו דורש, אם יש
  }
};
```

איפה מוצאים את זה בבראבו: פותחים את קוד ההטמעה של הטופס.
`action="..."` שבתגית `<form>` הוא מה שנכנס ל־`action`, ו־`name="..."` של כל
`<input>` הוא מה שנכנס ל־`fields`. אם יש בקוד `<input type="hidden">` — כל אחד
כזה צריך להיכנס ל־`extra`.

**כל עוד `action` ריק העמוד במצב הדגמה:** הטופס לא נשלח לשום מקום, והמדריך פשוט
נפתח. שימושי לבדיקת עיצוב, לא לשימוש אמיתי.

השליחה מתבצעת דרך iframe נסתר, כך שהגולשת נשארת בעמוד ולא מנווטת לדף של בראבו,
ואין צורך בהגדרות CORS בצד בראבו.

## 2. איפה מארחים

הקובץ עצמאי לחלוטין — אין קבצים נלווים, אין תלויות. אפשר להעלות אותו כמו שהוא:

- **לאתר קיים** — להעלות ל־FTP לתיקייה כלשהי, למשל `https://your-site.co.il/celiac/`
- **Netlify Drop** — גוררים את התיקייה `landing` ל־[app.netlify.com/drop](https://app.netlify.com/drop), מקבלים כתובת מיד
- **GitHub Pages** — מפעילים Pages על הרפו ומצביעים על התיקייה `landing`

הפונטים (Assistant + Frank Ruhl Libre) נטענים מ־Google Fonts, כך שנדרש חיבור
אינטרנט. אם רוצים עמוד שעובד גם בלי — מוחקים את שתי שורות ה־`<link>` ל־fonts
והדפדפן ייפול חזרה לפונט מערכת.

## 3. הלינק למאניצ'ט

מדביקים את הכתובת של העמוד כפי שהיא. אפשר להוסיף בסוף `?src=manychat` —
הערך יישלח לבראבו בשדה `source` (אם הגדרת אצלך שדה כזה), וכך רואים מאיפה
הגיע כל ליד:

```
https://your-site.co.il/celiac/?src=manychat
```

## 4. מה עוד יש בעמוד

- **ולידציה בעברית** לשם, לטלפון (פורמט ישראלי, כולל +972) ולאימייל
- **צ'קבוקס אישור דיוור** — חובה לסמן לפני שליחה
- **מלכודת ספאם** נסתרת: בוט שממלא אותה לא מגיע לבראבו
- **זיכרון מקומי**: מי שכבר מילא פעם אחת מקבל את המדריך ישירות בכניסה הבאה
- **גיליון הדפסה** נפרד: הטופס נעלם, המדריך יוצא נקי ל־PDF, והכרטיס לתלייה
  לא נחתך בין עמודים
- **שדות למילוי** בכרטיס ובפרטי התלמיד/ה — אפשר להקליד לפני ההדפסה

### כפתור ההורדה

בסוף המדריך יש שני כפתורים: **הורדת המדריך לשמירה** ו**הדפסה / שמירה כ־PDF**.

ההורדה בונה בדפדפן קובץ HTML עצמאי שמכיל רק את המדריך — בלי הטופס, בלי
הודעת התודה ובלי הכפתורים — כולל כל העיצוב וכולל מה שהמשתמש/ת הקליד/ה
בשדות (שם התלמיד/ה, כיתה, טלפונים). הקובץ נפתח בכל דפדפן גם בלי אינטרנט
(רק הפונטים ייפלו לפונט מערכת), ואפשר לשלוח אותו הלאה בוואטסאפ או במייל.

הקובץ יורד בשם `madrich-celiac-bekita.html`. השם באנגלית בכוונה: חלק
מהדפדפנים פוסלים שם קובץ בעברית ושומרים אותו כ־`download` בלי סיומת, וכך
הוא לא נפתח בלחיצה. אפשר לשנות אותו במשתנה `FILENAME` בתחתית הקובץ —
רצוי להישאר באותיות לטיניות.

הערה: החשיפה של המדריך היא בצד הדפדפן. מי שיודע לפתוח כלי מפתחים יוכל לעקוף
את הטופס. זה סטנדרטי בעמודי לידים מסוג זה; אם חשוב חסימה אמיתית, צריך להגיש
את המדריך משרת אחרי אישור הליד.
