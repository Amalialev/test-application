# עמוד לידים — "צליאק בכיתה: מה חשוב לדעת"

עמוד נחיתה בקובץ אחד (`index.html`): אוסף שם, טלפון ואימייל, שולח את הליד ליעד
שבחרת, ומיד אחר כך חושף את המדריך המלא באותו עמוד — כולל הורדה והדפסה.
בנוי כדי להיות מודבק כלינק במאניצ'ט.

---

## 1. לאן הולכים הלידים

בתחתית `index.html` יש בלוק הגדרות אחד, `LEAD`, ובתוכו `mode`:

| `mode` | מה קורה | מתי להשתמש |
|---|---|---|
| `"demo"` | הליד לא נשלח לשום מקום, המדריך פשוט נפתח | בדיקות עיצוב בלבד |
| `"netlify"` | הלידים נאספים בדשבורד של Netlify, עם ייצוא ל־CSV | לאסוף עכשיו, לייבא ל־Brevo אחר כך |
| `"post"` | הליד נשלח ישירות ליעד חיצוני — Brevo וכו' | כשה־Brevo מחובר |

אפשר להתחיל ב־`"netlify"`, לאסוף לידים, ולעבור ל־`"post"` בהמשך — בלי לשנות
שום דבר אחר בעמוד.

---

## 2. לאסוף עכשיו, לייבא ל־Brevo אחר כך

זו הדרך לעלות לאוויר בלי לחכות לחיבור ל־Brevo.

**חשוב לדעת:** העמוד הוא HTML סטטי — אין לו שרת משלו ואין לו איפה לשמור לידים
בעצמו. `localStorage` נשמר אצל הגולש/ת במכשיר שלו/ה, לא אצלך, אז הוא לא פתרון
לאיסוף. חייבים יעד חיצוני כלשהו שיקבל את הפרטים. `"netlify"` הוא היעד שדורש
הכי פחות: הוא כבר כלול באחסון עצמו, בלי הרשמה לשירות נוסף.

### שלב א — להעלות ל־Netlify

גוררים את התיקייה `landing` ל־[app.netlify.com/drop](https://app.netlify.com/drop).
מקבלים כתובת מיד. (צריך חשבון Netlify חינמי כדי שהטפסים יופעלו.)

### שלב ב — להדליק את המצב

בתחתית `index.html`:

```js
var LEAD = {
  mode: "netlify",     // ← במקום "demo"
  ...
};
```

מעלים שוב את התיקייה. זהו.

הטופס ב־HTML כבר נושא `name="celiac-guide-leads"` ו־`data-netlify="true"`,
שזה מה ש־Netlify מחפש בזמן הדיפלוי. אין מה להוסיף.

### שלב ג — למשוך את הלידים כשמגיעים למחשב

בדשבורד של Netlify: **Forms → celiac-guide-leads → Download CSV**.
ה־CSV מכיל שם, טלפון, אימייל, אישור דיוור, מקור (`source`) וחותמת זמן.

### שלב ד — לייבא ל־Brevo

ב־Brevo: **Contacts → Import contacts → Upload a file**, מעלים את ה־CSV
וממפים את העמודות: `name` → FIRSTNAME, `email` → EMAIL, `phone` → SMS.
בוחרים את הרשימה, ומסמנים שהאנשים נתנו הסכמה (העמודה `consent` היא התיעוד
שלך לכך).

הטלפון נשלח כבר בפורמט בינלאומי — `+972521234567` — כי זה מה ש־Brevo דורש
בשדה SMS. אם מעדיפים `0521234567`, משנים ל־`phoneFormat: "local"`.

## 3. לחבר את Brevo ישירות

כשרוצים שהלידים יגיעו ל־Brevo בזמן אמת במקום דרך CSV:

ב־Brevo יוצרים טופס (**Contacts → Forms**) ופותחים את קוד ההטמעה שלו. משם:

- `action="https://sibforms.com/serve/XXXXXXXX"` שבתגית `<form>` → נכנס ל־`action`
- ה־`name` של כל `<input>` → נכנס ל־`fields`. ב־Brevo הם באותיות גדולות:
  `EMAIL`, `FIRSTNAME`, `SMS`
- כל `<input type="hidden">` שבקוד → נכנס ל־`extra`, למשל `locale`,
  `html_type` ו־`email_address_check` (זו מלכודת הספאם של Brevo וחייבת
  להישאר ריקה)

```js
var LEAD = {
  mode: "post",
  phoneFormat: "intl",
  action: "https://sibforms.com/serve/XXXXXXXX",
  fields: {
    name:    "FIRSTNAME",
    phone:   "SMS",
    email:   "EMAIL",
    consent: "OPT_IN",     // רק אם יצרת ב-Brevo אטריביוט כזה. אחרת למחוק
    source:  "SOURCE"      // אותו דבר
  },
  extra: {
    "email_address_check": "",
    "locale": "he"
  }
};
```

`consent` ו־`source` יישלחו רק אם השארת להם שם. אם אין לך אטריביוטים כאלה
ב־Brevo — מוחקים את השורות, אחרת Brevo עלול לדחות את הפנייה.

השליחה מתבצעת דרך iframe נסתר, כך שהגולשת נשארת בעמוד ולא מנווטת לדף התודה
של Brevo, ואין צורך בהגדרות CORS.

> אף פעם לא לשים כאן מפתח API של Brevo. הקובץ הזה גלוי לכל מי שנכנס לעמוד.
> טופס ההטמעה (`sibforms.com/serve/...`) בנוי להיות ציבורי — מפתח API לא.

## 4. איפה מארחים

הקובץ עצמאי לחלוטין — אין קבצים נלווים, אין תלויות:

- **Netlify Drop** — הכי מהיר, וגם היחיד שנותן איסוף לידים מובנה (`mode: "netlify"`)
- **לאתר קיים** — להעלות ל־FTP לתיקייה כלשהי, למשל `https://your-site.co.il/celiac/`
- **GitHub Pages** — מפעילים Pages על הרפו ומצביעים על התיקייה `landing`

`mode: "netlify"` עובד רק באחסון ב־Netlify. בכל אחסון אחר צריך `mode: "post"`.

הפונטים (Assistant + Frank Ruhl Libre) נטענים מ־Google Fonts, כך שנדרש חיבור
אינטרנט. אם רוצים עמוד שעובד גם בלי — מוחקים את שתי שורות ה־`<link>` ל־fonts
והדפדפן ייפול חזרה לפונט מערכת.

מדביקים את הכתובת של העמוד כפי שהיא. אפשר להוסיף בסוף `?src=manychat` —

```
https://your-site.co.il/celiac/?src=manychat
```

## 6. מה עוד יש בעמוד

- **ולידציה בעברית** לשם, לטלפון (פורמט ישראלי, כולל ‎+972) ולאימייל
- **צ'קבוקס אישור דיוור** — חובה לסמן לפני שליחה
- **מלכודת ספאם** נסתרת (`company`): בוט שממלא אותה לא נשלח לשום מקום
- **זיכרון מקומי**: מי שכבר מילא פעם אחת מקבל את המדריך ישירות בכניסה הבאה
- **גיליון הדפסה** נפרד: הטופס נעלם, המדריך יוצא נקי ל־PDF, והכרטיס לתלייה
  לא נחתך בין עמודים
- **שדות למילוי** בכרטיס ובפרטי התלמיד/ה — אפשר להקליד לפני ההדפסה

### כפתור ההורדה

בסוף המדריך יש שני כפתורים: **הורדת המדריך לשמירה** ו**הדפסה / שמירה כ־PDF**.

ההורדה בונה בדפדפן קובץ HTML עצמאי שמכיל רק את המדריך — בלי הטופס, בלי
הודעת התודה ובלי הכפתורים — כולל כל העיצוב וכולל מה שהמשתמש/ת הקליד/ה
בשדות (שם התלמיד/ה, כיתה, טלפונים). הקובץ נפתח בכל דפדפן גם בלי אינטרנט
(רק הפונטים ייפלו לפונט מערכת), ואפשר לשלוח אותו הלאה בוואטסאפ או במייל.

הקובץ יורד בשם `madrich-celiac-bekita.html`. השם באנגלית בכוונה: חלק
מהדפדפנים פוסלים שם קובץ בעברית ושומרים אותו כ־`download` בלי סיומת, וכך
הוא לא נפתח בלחיצה. אפשר לשנות אותו במשתנה `FILENAME` בתחתית הקובץ —
רצוי להישאר באותיות לטיניות.

הערה: החשיפה של המדריך היא בצד הדפדפן. מי שיודע לפתוח כלי מפתחים יוכל לעקוף
את הטופס. זה סטנדרטי בעמודי לידים מסוג זה; אם חשוב חסימה אמיתית, צריך להגיש
את המדריך משרת אחרי אישור הליד.
